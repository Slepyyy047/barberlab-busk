# BARBERLAB — візуальна система

Чорний фон, мідний акцент, велика типографіка й надані портрети. Основний мотив — точний зріз: слово збирається з двох частин, тонкі лінії ведуть погляд, фотографії розкриваються вертикально. Перший екран залишається чистим і одразу дає перехід до запису.

## Палітра й композиція

- Основа: #090909; поверхні: #101010, #111111 і #1a1410.
- Акцент: #d88756; основний текст: #f0efec; другорядний текст достатньо світлий для темного фону.
- Локальний Manrope. Ліцензії шрифтів і походження матеріалів описані на /licenses та в assets/.
- Порядок головної: перший екран → безперервна текстова стрічка → підхід → команда → послуги → відгуки → питання → контакти → фінальний запис.
- На телефоні майстри стоять у два стовпці; остання непарна картка центрована. Хедер закріплений, нижня кнопка запису доступна під час прокручування.

## Рух

Використані принципи build-awwwards-quality-sites та animation-systems із наявним стеком проєкту: CSS, IntersectionObserver і requestAnimationFrame. Прокручування браузерне; нових залежностей немає.

- Заголовок з’являється і складається за 1,2 секунди. Наприкінці декоративні половини зникають, залишається ціле доступне слово.
- Рухи мають спільне м’яке сповільнення, меншу амплітуду й короткі затримки. Під час прокручування рядки заголовка трохи розходяться; машинка й контурний напис рухаються в протилежних напрямках зі згладжуванням 125 мс.
- Адреса з CMS помітна на першому екрані й веде до контактів. Декоративний маркер повільно пульсує лише у видимій зоні.
- Основна кнопка «Записатися на стрижку» має висоту 78 пікселів на комп’ютері та 70 на телефоні. Наведення чи клавіатурний фокус проявляє світлішу заливку й змінює стрілку по діагоналі без зміни розмірів кнопки.
- Портрети відкриваються з невеликою затримкою; стрілка з’являється при наведенні чи фокусі й постійно видима на телефоні.
- Вибір послуги проявляє мідну заливку й деталі візиту. На телефоні натискання підводить до результату; вибір клавіатурою залишає фокус на варіантах.
- Відгуки показані повністю у статичних картках: три стовпці на широкому екрані, один на телефоні. Немає каруселі, обрізання рядків чи прихованих сусідніх відгуків.
- Cookie-панель плавно з’являється справа внизу; на телефоні розташована над кнопкою запису.

prefers-reduced-motion і «Зупинити анімації» переводять рух у завершений статичний стан. Контент доступний без JavaScript. Геометрія для прокручування зчитується перед зміною стилів лише після нового прокручування або зміни розміру. Кадри припиняються, коли значення досягли цілі; обробники й спостерігачі очищуються при переході між сторінками.

## Запис і дані

Послуги, ціни, тривалість, видимість майстрів, портрети, відгуки та контакти беруться з CMS. На головній одразу обрана перша опублікована послуга: видно ціну, тривалість і кнопку запису. Іншу послугу можна обрати зі списку. Цей вибір — підказка, а не підтверджене бронювання. Далі відкривається точне посилання Altegio з налаштувань; послугу, майстра та час відвідувач обирає там.

Немає вигаданої доступності, знижок, таймерів, доданих відгуків чи прихованого стеження. Рейтинг позначений як надані дані. Посилання на портрет веде до відповідної картки на /team. Інтер’єр і роботи майстрів не підміняються вигаданими фото.

## Матеріали й маршрути

На головній використані п’ять наданих портретів, раніше підготовлений логотип та одна декоративна машинка з наявного набору. Портрети мають альтернативні описи й адаптивні розміри та зберігають природні кольори. Головна й /team завантажують повнорозмірні імпортовані файли без повторного стиснення Next Image: 800×800, для Андрія — 533×800. Дані CMS і вихідні зображення не змінені. Декоративні елементи приховані від скринридера. Походження ілюстрацій: assets/tool-generation.md; логотипа: assets/logo-generation.md. Раніше створений фоновий колаж на головній не використовується.

Сторінки /services, /team, /contacts, правові сторінки, адміністративний кабінет і дані збережені. /gallery та /about зберігають наявні перенаправлення.

## Перевірка

npm run lint, npm run typecheck, npm test, npm run build, npm run smoke, npm run test:accessibility.

Браузерні перевірки охоплюють мобільне меню, фокус, контраст, згоду на Google-карту та її відкликання, актуальні ціни, точне посилання запису, відсутність FAQ, повні тексти відгуків, завершений заголовок, reduced-motion і роботу без JavaScript. Smoke та браузерні тести працюють із тимчасовими тестовими даними. Конверсію потрібно вимірювати на реальному трафіку; візуальне оновлення саме по собі не доводить її зростання.

## Компактна подача

На головній залишені короткий опис, майстри, послуги з цінами, справжні відгуки, контакти. Прибрані дубльований відгук у hero, повторний заклик після команди та мотиваційні підводки. Заголовки прямо називають вміст секцій. Зменшені міжсекційні відступи, розмір декору та фінального блоку запису.

Поширені запитання прибрані з головної. Заголовок першого екрана — «Чоловічі стрижки. Догляд за бородою.». Поруч показані три надані портрети видимих майстрів із CMS; на мобільному вони розташовані під заголовком. Композиція веде до секції команди.
