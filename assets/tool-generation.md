# Barber tool cutout generation

Built-in `image_gen.imagegen`; one image per object; `transparent_background: true`; square PNG outputs copied directly from the generator output paths to `public/generated-tools/<slug>.png`. No post-processing was applied, preserving source alpha. All 15 final images were individually reviewed for subject identity, complete silhouette, and suitability as low-contrast decorative cutouts. The neck-duster asset was regenerated once after the first result resembled a shaving brush.

The shared visual requirements in each prompt specify photorealistic studio 3/4 view, centered full object with transparent padding, dark graphite/brushed steel/warm copper detailing, soft rim light for a near-black site, and no branding, text, humans, or unrelated props.

## scissors

```text
Create a single photorealistic studio product cutout of classic professional barber scissors, 3/4 view, gently open, centered and fully visible with generous transparent padding all around. Dark graphite handles, brushed steel blades, tiny warm copper pivot accent. Crisp realistic metal, soft controlled rim lighting suitable as a small decoration on a near-black website. No brand, no lettering, no logo, no people, no hands, no extra objects. Truly transparent background, clean isolated silhouette. Square PNG composition.
```

The handle must be fully visible and distinctly much longer than the bristle head. Dark graphite handle, subtle brushed-steel ferrule, restrained copper ring. Entire object centered, generous transparent padding, crisp studio product photo, soft rim light for a near-black website decoration. No logo, label, text, no people, hands, extra objects. Truly transparent background. Square PNG.
