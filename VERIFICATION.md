# Перевірка коригувальної ітерації · 09.10.2026

До змін пройшли 13 серверних тестів. Помилку категорій відтворено в Edge до редагування: рядки після перемикання мали opacity:0 без помилок JavaScript. Причина — старий спостерігач збирав елементи один раз, а глобальний CSS приховував нові рядки.

Виправлення: елементи анімації підключаються окремо, нові вузли враховуються, фільтровані послуги не залежать від появи при прокручуванні. Категорії нормалізуються; приховані послуги не передаються до публічного списку. Для порожніх категорій є пояснення українською.

## Результати

- 13/13 серверних тестів; ESLint, TypeScript та production build пройшли.
- node tests/filter-regression.mjs: усі категорії, швидке перемикання, повернення до всіх послуг на desktop/mobile/reduced motion.
- node tests/corrective-browser.mjs: сім маршрутів на desktop і mobile, пряме відкриття та оновлення, меню, touch-фільтри, посилання, прокручування вниз/назад, реальні п’ять портретів, зменшення руху, відсутність JavaScript, примусова помилка IntersectionObserver.
- node tests/run-corrective-isolated.mjs: окремий сервер :3111 і тимчасова база. Зміни категорій/цін/видимості через захищений CMS API, порожня категорія, команда з 1/2/5 майстрами, відсутні портрети, зум і фокус без зсувів сусідніх карток, повторне відкриття/Escape галереї з відновленням фокуса. Тимчасові файли та база прибрані.
- node tests/run-isolated-admin.mjs: окремий :3101 і тимчасова база. Вхід, UI редагування послуг і контактів, завантаження/видалення фото, галерея та ширина 360 px пройшли. Обліковий запис, медіа та база прибрані.
- У свіжих браузерних звітах немає необроблених помилок JavaScript.

## Спостереження продуктивності

Один локальний прогін до/після, Edge 1440×900: головна 6316 → 3089 px; файли шрифтів 9 → 4; запити зображень головної 4 → 2, тепер лише логотип. Загальна кількість ресурсів лишилась 27 через інші завантаження та попереднє завантаження маршрутів. Медіана виміряних інтервалів кадрів близько 11.1 ms в обох прогонах; довгі завдання 1 → 0, CLS 0 → 0. Це локальні спостереження, а не гарантія швидкості на реальному телефоні або повільній мережі. Порівняння обсягів передавання не заявляється: методи вимірювання розміру в прогонах відрізнялись.
